# 搬瓦工（BandwagonHost）接入指南

搬瓦工的 KiwiVM 面板提供官方 API，本工具直接调用，无需登录服务器，也不用装任何东西。

用到一个端点：

| 端点 | 取什么 |
|---|---|
| `GET https://api.64clouds.com/v1/getServiceInfo?veid=…&api_key=…` | 本账期累计已用（`data_counter`）、月配额（`plan_monthly_data`）、流量系数（`monthly_data_multiplier`）、下次重置时间（`data_next_reset`）、暂停状态（`suspended`） |

与 Vultr 有一个本质区别：**KiwiVM 只给账期累计计数器，没有按天的历史序列**。
本工具在本地记一份快照，用「计数器差值」还原每日用量（详见下文[工作原理](#工作原理)）。

---

## 一、拿到 VEID 与 API Key

两者都在 KiwiVM 面板（`https://kiwivm.64clouds.com/`）：

1. 登录后进入你要监控的那台 VPS
2. 左侧菜单最下方 → **KiwiVM API**
3. 页面上会显示 **VEID** 和 **API key**

> ⚠️ KiwiVM 的 API Key 是**按 VPS 发的**，不是账号级的 —— 每台机器一对凭据，
> 与 Vultr「一个 Key 管整个账号」不同。所以本工具把它填在**每台服务器**的编辑页里。

> 该 Key 能控制这台 VPS（重启、重装等），不要提交进仓库或发给别人。

---

## 二、填入工具

设置界面 → 服务器配置 → 添加 → **搬瓦工**：

| 字段 | 填什么 |
|---|---|
| VEID | 面板上那串数字 |
| KiwiVM API Key | 面板上那串密钥（macOS 存系统钥匙串；Windows 用 DPAPI 加密。**都不写进 config.json**） |
| 月配额 | 填 `0`：自动采用 API 报告值（已乘流量系数，与面板一致） |
| 每月重置日 | 对照面板上的**「下次重置」日期**填它对应的「日」（搬瓦工按开通周年日重置，每人不同）。填错工具会在面板上提醒 |
| 计费口径 | 保持「仅出站」—— KiwiVM 返回的是单一合并计费值（见下文） |
| GB 进制 | 默认 binary（KiwiVM 面板按 1024³ 展示） |

填完点「测试连接并采集」，成功后界面应显示与 KiwiVM 面板一致的已用 / 配额。

macOS 也可以先在命令行验证凭据（不用先写配置）：

```bash
cd macos
swift run vpsquota-cli bwg-probe <VEID> <API_KEY>
```

## 三、工作原理：累计计数器怎么变成每日流量

KiwiVM 的 `data_counter` 是**本计费周期开始以来的计费字节总量**，只增不减（换账期时归零）。
本工具在每个 VEID 的本地快照文件（`bwg-state/<veid>.json`，与数据库同目录）里记三个值，
每次采集做差：

```
当天用量 = 当前计数器 − 当日基线
```

- **同一天内**每次刷新都是绝对重算，覆盖写入天然幂等；
- **跨天**时，昨天最后一次观测值成为今天的基线；
- **换账期**（计数器回落，或下次重置时间变化）时基线归零。

由此带来几个需要知道的行为：

| 场景 | 表现 |
|---|---|
| 首次接入 | 面板当前已用量**整体记到当天**，账期总量立即正确；趋势图首日有一根大柱子。**不要再填「起始已用量」**，会把同一段流量补两遍 |
| 应用停采几天（关机 / 休眠） | 停采期间的增量整段记到**恢复采集那天**，账期总量仍正确，只是那天的柱子偏高 |
| 重置发生在一天中间 | 工具按 UTC 零点切账期，重置当天的归属有半天级别的偏差，属正常 |
| 停采跨过了重置日 | 新账期从 0 起算，旧账期的收尾数字停留在最后一次成功采集 |

## 四、流量系数（monthly_data_multiplier）

部分机房（如 CN2 GIA 系列）带宽更贵，KiwiVM 用一个系数折算：**已用与配额都要乘它**。
例如套餐标称 1000GB、系数 0.25 时，面板实际显示 250GB。

本工具按官方口径自动乘系数，所以**面板数字与工具数字应该一致**；
你不需要填、也没有地方填这个系数。

## 五、速率限制

KiwiVM API 有积分制速率限制（15 分钟 / 24 小时两档）。
单台机器每次刷新只发一个请求，按默认「每小时」刷新离限值很远，不必调更频繁。

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 报「KiwiVM API 报错（error 3）…」 | VEID 与 API Key 不匹配。注意 Key 是按 VPS 发的，别把另一台的填进来 |
| 配额/已用与面板差一个倍数 | 面板显示的是乘过系数的值；本工具也乘了。若仍不一致，检查「计费口径」是否被改成了「双向求和」——搬瓦工应保持「仅出站」 |
| 面板提醒「重置日不一致」 | 「每月重置日」与 KiwiVM 的下次重置日期对不上，按提醒改成面板那个「日」 |
| 换了新机器 / 重装系统后 VEID 变了 | 旧快照按 VEID 存，新 VEID 会按「首次接入」重新对齐，无需清理 |
